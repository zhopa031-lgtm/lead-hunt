# AI Lead Hunter

Ищет реальные заказы на сайты в публичных Telegram-каналах. AI внутри нет: оценка считается по понятным правилам, причина показана в каждой карточке.

Запуск (Node 22.13+, зависимостей нет):
1. Скопируйте .env.example в .env и задайте ADMIN_PASSWORD
2. npm start, откройте http://127.0.0.1:3000
3. Настройки: добавьте публичные каналы, где просят сайты, нажмите «Запустить поиск»

Каждый лид хранит дословный текст и ссылку на исходный пост. Сообщения сами не отправляются.
